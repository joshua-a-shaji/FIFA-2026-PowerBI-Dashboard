## 📌 Project Overview
This repository contains an interactive **Power BI Dashboard** analyzing squad metrics, player stats, team valuations, and key insights for the **FIFA 2026 World Cup**. The goal of this project is to explore team dynamics, key performance indicators (KPIs), and predictive insights through data visualization and advanced DAX modeling.

## 📊 Key Features & Dashboard Highlights

* **Executive Summary**: High-level KPIs including total players, squad valuations, age distributions, and top-performing leagues.
* **Player & Squad Performance**: In-depth comparison of player metrics (goals, assists, market value, position analysis).
* **Team & Regional Insights**: Regional breakdown across confederations and country squad comparisons.
* **Interactive Filters**: Slicers for teams, positions, leagues, and age groups for custom slice-and-dice capability.

---

## 🛠️ Tools & Technologies

* **Power BI Desktop**: Dashboard design, visual layout, and interactive slicers.
* **Power Query**: Data cleaning, transformation, handling missing values, and column structuring.
* **DAX (Data Analysis Expressions)**: Custom measures, calculated columns, and KPI aggregations.
* **Excel / CSV**: Primary data source ingestion.
